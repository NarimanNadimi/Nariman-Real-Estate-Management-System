## 🏡 درباره پروژه

نرم‌افزار جامع مدیریت املاک نریمان، یک برنامه برای سامان‌دهی فرایندهای اصلی دفاتر مشاور املاک است؛ از ثبت و مدیریت فایل‌های ملکی و نیازهای مشتریان گرفته تا پیدا کردن گزینه‌های مناسب، پیگیری ارتباطات، مدیریت قراردادها و بررسی گزارش‌های کاری.

هدف پروژه این است که اطلاعات پراکنده در یک فضای کاری منظم جمع شوند تا دسترسی به اطلاعات، پیگیری فرصت‌ها و مدیریت امور روزانه ساده‌تر شود.

> این مخزن برای معرفی محصول و نمایش قابلیت‌های آن ساخته شده است. فایل اجرایی و سورس‌کد برنامه در این مخزن منتشر نمی‌شوند.

## ✨ قابلیت‌های کلیدی

### 🏠 مدیریت فایل‌های ملکی
- ثبت و سامان‌دهی اطلاعات املاک و جزئیات هر فایل
- دسته‌بندی فایل‌ها بر اساس نوع ملک، موقعیت و نوع معامله
- ثبت اطلاعات مالی، متراژ، امکانات و توضیحات تکمیلی
- نگهداری اطلاعات مرتبط با فایل‌ها و سوابق تغییر قیمت

### 👥 مدیریت مشتریان و خواسته‌ها
- ثبت اطلاعات مشتریان و نیازهای ملکی آن‌ها
- سامان‌دهی فایل‌های واگذاری و خواهان‌ها
- نگهداری اطلاعات موردنیاز برای پیگیری و ارتباط با مشتریان
- مدیریت مراحل پیگیری در جریان کاری مشتریان

### 🧠 تطبیق هوشمند ملک و خواسته مشتری
- بررسی تناسب فایل‌های موجود با خواسته‌های ثبت‌شده
- درنظرگرفتن معیارهایی مانند نوع ملک، موقعیت، بودجه، متراژ و امکانات
- نمایش امتیاز و جزئیات مرتبط با میزان تطبیق
- کمک به اولویت‌بندی گزینه‌های مناسب برای بررسی بیشتر

### 🔄 پایپ‌لاین و پیگیری فرایندها
- نمایش مرحله‌ای روند پیگیری مشتریان و فرصت‌ها
- مدیریت فعالیت‌های مرتبط با پرونده‌ها
- پشتیبانی از قوانین گردش‌کار برای برخی فرایندهای قابل تنظیم

### 📞 ابزارهای ارتباطی و پیگیری
- مدیریت مخاطبان و اطلاعات تماس
- ثبت و پیگیری تماس‌ها و فعالیت‌ها
- مدیریت وظایف، یادآورها و قرار ملاقات‌ها
- آماده‌سازی پیام‌های از پیش تنظیم‌شده برای اشتراک‌گذاری از طریق واتساپ

*آماده‌سازی پیام واتساپ به معنی ارسال خودکار پیام نیست؛ کاربر می‌تواند پیام را بررسی و سپس ارسال کند.*

### 📑 قراردادها و کمیسیون
- ثبت و پیگیری اطلاعات قراردادها
- مدیریت مشاوران و سهم کمیسیون
- محاسبه سهم کمیسیون بر اساس تنظیمات ثبت‌شده
- تهیه نسخه قابل چاپ و خروجی PDF از قراردادها
- پیگیری تاریخ‌های مهم و سررسید قراردادها

### 💰 امور مالی و سررسیدها
- سامان‌دهی اطلاعات مالی ثبت‌شده در برنامه
- پیگیری چک‌ها و تاریخ سررسید آن‌ها
- نمایش یادآوری برای موارد نزدیک به سررسید
- دسترسی به اطلاعات مالی از بخش گزارش‌ها

### 📊 داشبورد و گزارش‌های مدیریتی
- مشاهده خلاصه‌ای از فعالیت‌ها و اطلاعات ثبت‌شده
- بررسی توزیع فایل‌ها بر اساس دسته‌بندی و منطقه
- تحلیل وضعیت خواسته‌های مشتریان و فایل‌های موجود
- بررسی نتایج تطبیق ملک و خواسته
- گزارش عملکرد منابع جذب مشتری و مشاوران
- مرور آمار قراردادها، کمیسیون‌ها و فعالیت‌های مالی

گزارش‌ها بر پایه داده‌هایی هستند که در برنامه ثبت شده‌اند.

### 🗓️ ابزارهای بهره‌وری
- تقویم و مدیریت قرارها
- وظایف و یادآورها
- ثبت تماس‌ها و فعالیت‌های مرتبط با مشتری
- بخش پیام‌ها و تیکت‌های داخلی برنامه
- جست‌وجو و دسترسی سریع به بخش‌های مختلف

### 💾 ذخیره‌سازی و پشتیبان‌گیری
- نگهداری محلی داده‌های برنامه
- پشتیبانی از ذخیره‌سازی رسانه‌های مربوط به رکوردها
- خروجی گرفتن از اطلاعات در قالب فایل پشتیبان JSON
- بازیابی اطلاعات از فایل‌های پشتیبان سازگار

**نکته فنی:** معماری فعلی بر ذخیره‌سازی محلی متمرکز است. همگام‌سازی ابری یا همگام‌سازی خودکار اطلاعات بین چند دستگاه، جزو قابلیت‌هایی نیست که این مخزن وعده می‌دهد.

## 🎨 تجربه کاربری

- رابط کاربری فارسی و راست‌چین (RTL)
- پوسته روشن و تیره
- طراحی واکنش‌گرا برای اندازه‌های مختلف صفحه
- داشبورد و صفحات مدیریتی یکپارچه
- جست‌وجو، فیلتر و مرتب‌سازی اطلاعات
- میانبرهای صفحه‌کلید و دسترسی سریع به بخش‌ها

## 🛠️ فناوری‌های مورد استفاده

| فناوری | کاربرد |
|---|---|
| React | ساخت رابط کاربری |
| JavaScript | منطق و تعاملات برنامه |
| HTML & CSS | ساختار، طراحی و چیدمان |
| SheetJS (xlsx) | پردازش داده‌های صفحه‌گسترده |
| Browser Storage APIs | ذخیره‌سازی محلی داده‌ها |
| IndexedDB | نگهداری رسانه‌های پشتیبانی‌شده |
| html2canvas & jsPDF | تولید خروجی PDF برای اسناد پشتیبانی‌شده |

بخش‌های در نظر گرفته‌شده برای پیش‌نمایش:

- نتایج تطبیق ملک و خواسته
- پایپ‌لاین پیگیری
- قراردادها و کمیسیون
- گزارش‌ها و تنظیمات
